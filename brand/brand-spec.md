# 3ZAI Voice Studio — Brand Spec

- **Primary logo:** `brand/3zai-logo.svg` — SVG الدائري الأصلي المستخرج من HTML الذي أرفقه المستخدم. تستخدمه الواجهة كملف صورة عبر `/3zai-logo.svg`، وليس كرسمة بديلة.
- **Favicon:** `client/public/favicon.svg` — النسخة نفسها من الشعار الأصلي.
- **Platform logo:** رابط CDN محفوظ حرفياً في `app.config.ts`.
- **User references:** `/home/ubuntu/upload/pasted_content.txt` و`/home/ubuntu/upload/pasted_content_2.txt` (مرفقات المستخدم: شاشة الدخول وواجهة المحادثة).
- **Signature colors:** خلفية داكنة `#0b0d12`، سطح `#14171f`، لون العلامة/التأكيد `#e08e6f`، لون النص `#eef0f4`، والثانوي `#98a2b3`.
- **Typography:** Inter مع Noto Sans Arabic وSegoe UI كبدائل نظامية.
- **Motion:** انتقالات قصيرة بمنحنى `cubic-bezier(.22,.61,.36,1)`، مع تقليل الحركة عند `prefers-reduced-motion`.
- **Positioning:** استوديو صوت عربي/إنجليزي لمعاينة استنساخ الصوت بموافقة المستخدم قبل اعتماده وتوليد الكلام.
