# متغيرات بيئة 3ZAI Voice Studio على Vercel

> **مهم:** هذا الملف يحتوي أسماء المتغيرات وأغراضها فقط. لم تُدرج فيه أي قيمة API key أو كلمة مرور أو رابط اتصال يحتوي بيانات دخول. لا تطلب القيم السرية في المحادثة ولا تحفظها في Git؛ أضفها مباشرةً في لوحة Vercel.

## إعدادها في لوحة Vercel

افتح مشروع Vercel ثم **Settings → Environment Variables**. أضف المتغيرات المطلوبة إلى بيئة **Production**، وإلى **Preview** إن كنت ستختبر معاينات Git. عيّن المفاتيح وكلمات المرور على أنها **Sensitive**، ثم أعد النشر بعد الحفظ. يجب أن تكون متغيرات البناء متاحة للبناء أيضاً عند إنتاج ملف إعداد المتصفح العام.

| اسم المتغير | مطلوب؟ | الحساسية | الاستخدام |
|---|---:|---|---|
| `DATABASE_URL` | نعم | **سري** | اتصال MySQL للمستخدمين والمحادثات والرسائل والأصوات والتفضيلات. لا تضع هذا الرابط في المتصفح أو Git. |
| `MANUS_JWT_SECRET` | نعم | **سري** | توقيع والتحقق من ملفات جلسة الدخول. |
| `MANUS_API_KEY` | نعم للتخزين السحابي | **سري** | اعتماد خادمي لرفع وتنزيل الملفات من تخزين Manus. |
| `ELEVENLABS_API_KEY` | نعم للصوت | **سري** | اعتماد ElevenLabs الخادمي لاستنساخ الصوت وTTS وSTT. |
| `MANUS_PROJECT_ID` | نعم | معرّف مشروع | معرّف التطبيق المستخدم في جلسة OAuth؛ ليس مفتاحاً سرياً، لكنه يجب أن يطابق مشروع Manus. |
| `MANUS_OAUTH_API_URL` | نعم | عنوان خدمة | عنوان خادم OAuth الذي يستخدمه الخادم لتبادل الرمز والتحقق من المستخدم. |
| `MANUS_OAUTH_PORTAL_URL` | نعم | عنوان خدمة | عنوان بوابة OAuth المعروض للمتصفح كي يبدأ تسجيل الدخول. |
| `MANUS_API_URL` | نعم للتخزين السحابي | عنوان خدمة | عنوان Forge/Manus Storage الذي يستعمله الخادم. |
| `MANUS_API_BROWSER_KEY` | لا، حسب تكامل العميل | مفتاح متصفح معلَن | إن كان التكوين يتطلبه، فهو المفتاح العام المخصص للمتصفح فقط؛ **لا تستخدم هنا `MANUS_API_KEY` أو أي اعتماد خادمي**. |
| `OWNER_OPEN_ID` | اختياري | معرّف مستخدم محمي | تلميح دور المالك/المشرف إن كان التطبيق يحتاج ذلك؛ اتركه غير معيّن خلاف ذلك. |

## يديرها Vercel تلقائياً

`PORT`, `NODE_ENV`, `VERCEL`, `VERCEL_ENV`, `VERCEL_URL` هي قيم تشغيل يحددها Vercel أو إطار التطبيق. لا تنشئ لها قيماً يدوية إلا إذا كان هناك سبب موثق؛ التطبيق يقرأ `PORT` عند التشغيل.

## قالب أسماء بلا قيم

يمكن نسخ الأسماء فقط إلى قائمة إعدادات Vercel ثم إدخال القيم مباشرة في لوحة Vercel:

```dotenv
DATABASE_URL=
MANUS_JWT_SECRET=
MANUS_API_KEY=
ELEVENLABS_API_KEY=
MANUS_PROJECT_ID=
MANUS_OAUTH_API_URL=
MANUS_OAUTH_PORTAL_URL=
MANUS_API_URL=
MANUS_API_BROWSER_KEY=
OWNER_OPEN_ID=
```

لا تملأ هذا القالب بقيم حقيقية ثم ترفعه إلى المستودع. مسار OAuth بعد تثبيت نطاق الإنتاج يجب أن يكون:

```text
https://<نطاق-Vercel>/api/oauth/callback
```

راجِع Manus للسماح بعنوان callback هذا إن كان التطبيق أو المشروع يطبق قائمة نطاقات مسموح بها.
